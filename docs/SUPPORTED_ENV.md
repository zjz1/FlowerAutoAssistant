# 支持矩阵与环境要求（FAA 1.0）

本文件说明 FAA 1.0 的**支持范围**、**最低环境**，以及超出范围时的行为。不确定自己的环境是否可用时，先运行：

```bat
rem 源码模式
.venv\Scripts\python.exe webui.py --check-env

rem 发行包（便携版）
backend\faa_webui.exe --check-env
```

输出会逐项标出 `OK / WARN / FAIL`，并给出修复建议；错误码解释见 [ERRORS.md](ERRORS.md)。

---

## 1. 支持矩阵

| 项目 | 支持范围 | 说明 |
|---|---|---|
| 操作系统 | **Windows 10 / 11 x64** | 发行包为自包含 WPF（.NET 8），无需另装运行时 |
| 模拟器 | **MuMu 模拟器 12** | 默认 ADB：`D:\Program Files\Netease\MuMu\nx_main\adb.exe`，地址 `127.0.0.1:16384` |
| 其他模拟器 | best-effort | 需自行用 `--adb` 指定 adb.exe、用 `--address` 指定连接地址；不承诺全部流程可用 |
| 游戏画面 | 横屏，引擎工作区 1280×720 | 引擎按 MAA 长边 1280 缩放截图；流程使用**相对坐标**，模拟器分辨率变化不影响定位 |
| 登录界面 | 固定尺寸 | 该界面相对坐标失效，使用「锚点 + 像素偏移」通道（已内置） |
| Python（源码模式） | **3.11+**（开发验证 3.13） | 发行包内置运行时，不需要 Python |
| 磁盘 | 发行包解压后约 **600 MB** | 后端 296 MB + WPF 壳 + 运行数据 |
| 内存 | 建议 4 GB 以上 | OCR（RapidOCR + ONNX Runtime）常驻占用为主 |

## 2. 网络与权限

- FAA 只监听 **`127.0.0.1`**，不对外网开放；不需要公网。
- 连接模拟器走本机 ADB（默认 `127.0.0.1:16384`）。
- 首次运行会在 `data/` 下生成配置、日志与截图缓存 → **程序目录必须可写**（不要放在 `Program Files`）。
- 不写入注册表、不安装服务；删除目录即可卸载。

## 3. 明确不支持

- macOS / Linux（不提供发行包，也不承诺兼容）。
- 游戏服务端维护、封号、排队等**游戏侧**问题（不属于本工具范围）。
- 多开、多账号并发、任务队列（1.x 规划之外）。
- 任何形式的自动更新 / 资源热更（1.0 不做）。

## 4. 已知限制

- 模板匹配依赖 `resource/template/` 的 38 个界面模板；游戏 UI 大改版后个别模板可能失效，届时以 OCR 通道为准并在后续版本更新模板。
- 默认 ADB 路径是写死的 MuMu 安装位置；装在别处时用 `--adb "X:\...\adb.exe"` 启动（源码模式）或在设置页确认连接地址。
- 诊断包（`--export-diag`）默认不含截图；如需提供现场截图，请自行确认不含个人信息后再附上。
